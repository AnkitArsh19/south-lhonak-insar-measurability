# Meteorological & Climate Data Directory

Store atmospheric model outputs and rainfall observations here for InSAR tropospheric correction and flood trigger analysis.

## Subdirectories

- `era5/`: Place ECMWF ERA5 reanalysis NetCDF (`.nc`) or GRIB files (pressure levels: temperature, geopotential, specific humidity) used by PyAPS / MintPy for atmospheric delay correction.
- `gpm/`: Place NASA GPM IMERG Final Run precipitation NetCDF4 / GeoTIFF / CSV files covering September 25 – October 05, 2023.
